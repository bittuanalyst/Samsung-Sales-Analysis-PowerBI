# Samsung Sales Analysis – Power BI Dashboard

## 📊 Project Overview

An interactive Power BI dashboard designed to analyze Samsung mobile
sales performance across products, cities, payment methods, customer
ratings, and monthly trends.

## 🎯 Objectives

- Track overall sales and transaction performance
- Analyze monthly sales and quantity trends
- Compare sales performance across mobile models
- Analyze payment method distribution
- Understand customer rating patterns
- Analyze city-wise sales and quantity

## 🛠️ Tools Used

- Power BI
- DAX
- Data Cleaning
- Data Visualization
- Data Modeling

## 📌 Key KPIs

| KPI | Value |
|---|---:|
| Total Sales | 769M |
| Total Quantity | 19K |
| Total Transactions | 4K |
| Average Order Value | 40K |

## 📈 Dashboard Analysis

### Monthly Performance
The dashboard tracks month-over-month growth and monthly quantity
performance.

### Mobile Model Performance
Sales are compared across iPhone SE, OnePlus Nord, and Galaxy Note 20.

### Payment Methods
Transactions are analyzed across UPI, Cash, Debit Card, and Credit Card.

### Customer Ratings
Customer ratings from 1 to 5 are visualized to understand rating distribution.

### Geographic Analysis
City-level sales and quantity are represented using geographic visualizations.
